WHAT IT IS

One self-contained HTML file (~3 MB) that opens the Arabian Sea and Bay of Bengal (6–22°N, 61–92°E) as a navigable 3D ocean volume

No install, no login, no server — runs offline from a pen drive or an email attachment

Real case study built in: Cyclone Amphan, May 2020 — HYCOM model analyses, 206 Argo profiles (with BGC chlorophyll and oxygen) and the IBTrACS track

HOW IT ADDRESSES THE PROBLEM

Model fields (temperature, salinity, currents) and in-situ Argo, BGC, glider and CTD profiles are drawn in the SAME 3D scene instead of separate portals

Click any float → its observed profile is drawn over the co-located model column with bias and RMSE, so model–observation agreement is visible in one glance

Depth slices, vertical sections, 3D isosurfaces, D20 / D26 surfaces, a cyclone heat potential map, current particle streaks, ETOPO1 bathymetry and coastline

INNOVATION AND UNIQUENESS

Existing tools (Ocean Navigator, MyOcean Pro, Argovis) need servers, accounts or live bandwidth; OceanLens 3D needs a browser; drag in your own CSV or NetCDF files

Density (EOS-80), sound speed (Mackenzie 1981) and cyclone heat potential computed live in the browser — not pre-rendered pictures

FEASIBILITY AND VIABILITY
WHY IT IS FEASIBLE
✓  Prototype existsFull 3D scene, float comparison and demo mode already run on real Cyclone Amphan data in one ~3 MB file, built by a working Python pipeline and checked by 159 automated tests.
✓  Data is free and openHYCOM, Argo GDAC, ETOPO1 and IBTrACS are public: no account needed, free to use with attribution; Copernicus Marine needs only a free registration.
✓  Runs on any laptopBrowser + WebGL only. No GPU cluster, no cloud bill, no IT deployment for a district office to use it.
✓  Built-in quality checksArgo QC flags, a density-inversion test and bias / RMSE against the model run inside the app, so bad data is flagged, not hidden.
RISKS → MITIGATION
Payload size vs. detailRegional subsetting + vertical regridding + 16-bit quantization keeps 8 analyses of model fields plus 206 Argo profiles to about 2.3 MB.
Weak GPUs on office laptopsLayered transparency instead of ray-marching: 11 textured depth layers, cheap on integrated GPUs; Three.js version pinned.
Sparse / gappy float coverageGaps are shown as gaps, never silently interpolated, so users are not misled about data density.
Long-term maintenanceOne pinned library and a standard-library build, no npm chain; a plugin API adds sensors and variables without touching the core.
